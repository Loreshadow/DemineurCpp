# DemineurCpp
Simple jeu du démineur en console fait en CPP(C++)

Le jeu fonctionne sur toutes taille de grilles du moment que la console l'accepte mais a un meilleur fonctionnement avec une grille comprise entre 5x5 et 15x15.

# Contrôles

Flèche directionnelles : Haut, Bas, Gauche, Droite
Touche Espace : Creuser une case
F : Planter un drapeau


# Compiler soi-même:
Installer Visual Studio 2026 ( ou tout autre éditeur de texte capable de compiler du cpp pour plus de faciliter)
Activer les extensions pour Cpp dans visual install manager.
Lancer le projet dans Visual Studio aller dans le menu Générer et cliquer sur "Générer la solution" .
Aller dans le dossier et lancer le jeu.

# Installer le .exe déjà compiler
Aller dans release et installer la dernière version du programme compiler et mis en ligne.
Puis lancer le jeu.

# Features
Taille de grilles/Nombre de mines réglable.
Système d'affichage et de navigation lors du jeux avec clavier au lieu de commande complexe avec les cordonnées.
Système de sauvegarde d'une partie permettant de continuer notre série de partie.
